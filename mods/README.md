# The mods that come with Kindle

Each folder is one mod, installed with Kindle in `Game\kindle\mods` and off until you switch it on
(the title screen or pause menu: **Mods**, the **Mods** tab). Each has a README for players. More mods,
each its own repo: [Kindle's README](../README.md#mods).

| Mod | Version | What it does |
|---|---|---|
| [Bonfire Fate](bonfire-fate/README.md) | 1.0.0 | Every few minutes fate pairs a random cause with a random effect. |
